# 外盘涨跌统计（网页版）

一个看外盘期货涨跌的静态网页：打开就能看到 **25 行品种**的实时涨跌幅（22 个商品 + 3 个美股指数），手机、电脑都适配。另有「上证指数」临时行，只在商品开盘前的两个窗口出现。

**在线地址：<https://wingtrade.github.io/futures-calc/>**

**点任意品种名**，新标签页直接打开该品种的**全屏 K 线**（新浪原版页面）。

## 文件一览

| 文件 | 作用 |
|---|---|
| `index.html` | 展示页（单文件：样式 + 全部前端逻辑） |
| `fetch.py` | 云端抓取起始价，写出 `data.json` |
| `data.json` | 起始价数据（Actions 每天多轮定时更新） |
| `.github/workflows/fetch.yml` | 定时任务配置 |
| `k/*.html` | 品种全屏 K 线镜像页 |
| `项目记录.md` | 项目唯一文档（机制 + 全史） |

> 不构成投资建议｜数据可能有延迟或错误，请谨慎参考
