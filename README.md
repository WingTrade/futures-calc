# 外盘涨跌统计（网页版）

一个看外盘期货涨跌的静态网页：打开就能看到 25 行品种的实时涨跌幅（22 个商品 + 3 个美股指数），手机、电脑都适配。

**在线地址：<https://wingtrade.github.io/futures-calc/>**

---

## 设计思路

### ① 数据分两类：起始价走云端，最新价走浏览器

**起始价**由 GitHub Actions 按节点定时抓取（商品 10:15 / 11:30 / 15:00 / 23:00 / 01:00 / 02:30 收盘节点 + 美股日线），写成 `data.json`；**最新价**则在打开网页后由浏览器直接向行情源要，15 秒刷新一次。涨跌幅 = 最新价 − 起始价，在浏览器本地计算。

为什么这么分：GitHub Pages 只是静态托管（没有后端服务器），好在行情源都开放 HTTP 接口，浏览器可以直接取——这就绕开了服务器成本，整套系统纯免费运行。美股 3 指数为收盘口径（最近两根日线收盘对比），全天固定、不随盘中波动。

### ② 行情源怎么选的（均为实测）

| 行情源 | 浏览器能直连吗 | 覆盖 | 定位 |
|---|---|---|---|
| 腾讯行情 `qt.gtimg.cn` | ✅ 可以（跨域全开） | 16 个品种 | 主力实时源 |
| 新浪行情 `hq.sinajs.cn` | ❌ 不行（防盗链 + 无跨域头） | 6 个品种：原糖 / 棉花 / 马棕油 / 铁矿 / 日橡胶 / 美燃油 | 全网唯一准实时（滞后 8-20 秒），必须中转 |
| TradingView | ✅ 可以 | 4 个品种 | 延时兜底（10-20 分钟） |

新浪那 6 个品种，其他家都没有准实时数据，所以必须想办法把新浪"接"过来——这就是 Cloudflare 中转的由来。

### ③ Cloudflare 中转：为什么、怎么做、为什么做了两条

**问题**：新浪行情接口有防盗链——只允许"从新浪自家页面发来的请求"（浏览器请求时会带一个 `Referer` 头标明来源页面，新浪会校验它是不是自家域名）；同时接口不开放跨域许可（没开 CORS，网页拿不到返回内容）。浏览器直接请求会被挡死。

**思路**：用一个"中间人"替浏览器去请求新浪——它加上新浪认可的 `Referer`，把数据原样转回来，并顺手打开跨域许可。这个中间人就是 **Cloudflare 的免费服务**（无需服务器、全球节点、额度足够个人用量）。

**落地与演进（两代）**：

1. **第一代：Cloudflare Worker**（地址形如 `*.workers.dev`）
   写了一个约 25 行的转发：请求 `hq.sinajs.cn` 时带上 `Referer: https://finance.sina.com.cn`，返回时加上 `Access-Control-Allow-Origin: *`。
   上线后发现一个坑：`workers.dev` 域名在国内不少网络下**直连会被重置（连接被掐断）**——电脑挂着代理能用，手机出门（无代理）就废了，这 6 个品种只能退到延时数据。

2. **第二代：Cloudflare Pages 直连通道**（地址形如 `*.pages.dev`）
   实测发现 Cloudflare **Pages** 的 `pages.dev` 域名国内可以直连。于是用 Pages 的"高级模式"（`_worker.js`）又部署了一个**同款转发服务**，作为手机等无代理场景的直连通道。

   现在前端同时配置两个地址，按序尝试：**先连 Pages（普适，手机也能用）→ 失败切 Worker（有代理时的兜底）**，单条通道 4 秒超时自动切换。

3. **两道都连不上也不慌**：那 6 个品种自动降级用腾讯 / TradingView 的延时数据顶上，页面照常显示、不白屏；其余品种不受影响。

<details>
<summary>展开：中转服务的核心代码（Worker 与 Pages 高级模式用同一份）</summary>

```js
export default {
  async fetch(request) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
      'Cache-Control': 'no-store',
    };
    if (request.method === 'OPTIONS') {
      return new Response(null, { status: 204, headers: cors });
    }
    const list = new URL(request.url).searchParams.get('list') || '';
    if (!/^[A-Za-z0-9_,\.]{1,500}$/.test(list)) {
      return new Response('bad list', { status: 400, headers: cors });
    }
    const resp = await fetch('https://hq.sinajs.cn/list=' + list, {
      headers: {
        'Referer': 'https://finance.sina.com.cn',
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/122 Safari/537.36',
      },
    });
    const buf = await resp.arrayBuffer();
    const h = new Headers(cors);
    h.set('Content-Type', 'application/javascript; charset=GBK');
    return new Response(buf, { status: resp.status, headers: h });
  },
};
```

</details>

### ④ 上证指数临时行（商品开盘前的参考）

国内商品 10:30 / 13:30 开盘前，需要参考 A 股对 10:15 / 11:30 的涨跌来预判。所以页面只在特定窗口显示"上证指数"这一行：

| 窗口 | 显示时段 | 对比基准 |
|---|---|---|
| 10:15 档 | 10:15 – 10:30 | 当天 10:15 的价（从当日分时数据回溯取点） |
| 11:30 档 | 11:30 – 13:30 | 当天 11:30 上午收盘价（11:30–13:00 休市显示 0.00%，13:00 后随行情跳动） |

其余时间不显示该行，也不产生任何网络请求。数据同样走腾讯行情接口、浏览器直连。

### ⑤ 电脑端 EXE（桌面出图工具）

除网页外，项目还有一个配套的 Windows 小工具（**不随本仓库分发**）：双击运行，几秒内生成一张与网页同款的表格图（PNG）并自动打开——适合快速截图存档、发群里对照。定位上：网页管"随时随地看实时"，EXE 管"一键出图留档"。

实现思路与网页端同源、但链路更简化：

- **起始价仍复用云端**：启动时拉 GitHub Pages / jsDelivr 上的 `data.json`（与网页同一份数据、同一套档位判定），两个源取较新的一份，避免 CDN 缓存拿到旧数据。
- **最新价改为本机直取**：桌面程序不受浏览器那两条限制（请求头可自由设置、跨域限制也不存在），直接请求新浪行情（带上 Referer 即可）一次拉齐 22 个品种——**连 Cloudflare 中转都不需要**，中转本来就是只给浏览器绕限制用的。
- **本地绘制图片**：用 Python + Pillow 计算涨跌幅并绘制表格（名称左对齐、数值右对齐、红涨绿跌，版式与网页一致），文件名按生成时间命名。
- **上证指数行同款逻辑**：只在 10:15–10:30 / 11:30–13:30 两个窗口出图时，才多一行「上证指数」（基准取当日分时、实时价取新浪）。
- 程序用 PyInstaller 打包为单文件，双击即用，无需安装任何环境。

## 数据流总览

```
云端（GitHub Actions，每天 9 轮定时）
    fetch.py ──抓起始价──▶ data.json
                              │
浏览器打开网页 index.html ◀────┘（读起始价）
    │
    ├─ ① 腾讯行情直连（16 品种，实时，15 秒轮询）
    ├─ ② 新浪行情 ←── Cloudflare 中转（6 品种，准实时 8-20 秒）
    │        主通道：sina-hq.pages.dev（国内可直连）
    │        备通道：forexfutures.jonsen.workers.dev（需代理，兜底）
    └─ ③ TradingView（4 品种，延时兜底，60 秒轮询）
              │
              ▼
    浏览器本地计算涨跌幅（最新价 − 起始价）→ 渲染表格（红涨绿跌）
```

- 打开即用本地缓存秒开，再补齐云端数据（不闪旧价）
- 切到后台自动暂停轮询省流，切回来立即刷新

| 文件 | 作用 |
|---|---|
