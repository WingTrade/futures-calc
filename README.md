# 外盘涨跌统计（网页版）

一个看全球外盘期货涨跌的静态网页：打开就能看到 25 行品种的实时涨跌幅（22 个商品 + 3 个美股指数），手机、电脑都适配。

**在线地址：<https://wingtrade.github.io/futures-calc/>**

## 怎么运作

```
GitHub Actions（每天 9 轮，按节点定时）──抓起始价──▶ data.json
                                                    │
打开网页 ─▶ 读 data.json（起始价）────────────────────┤
        ─▶ 腾讯行情直连（16 品种，15 秒刷新）──────────┤──▶ 页面表格
        ─▶ 新浪准实时（6 品种，经自建中转，8-20 秒）────┤     （红涨绿跌）
        ─▶ TradingView（4 品种，延时兜底）─────────────┘
```

- **起始价**：云端按节点定时抓取，与"最新价"对比得出涨跌幅
- **最新价**：浏览器端实时获取，不用刷新页面（15 秒自动更新；切到后台自动暂停省流；美燃油为延时备份源）
- **上证指数临时行**：仅在 `10:15–10:30` 与 `11:30–13:30` 两个窗口显示（国内商品开盘前参考用），其余时间不显示
- 打开即时呈现：本地缓存秒开，再补云端数据，不闪旧价

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 展示页（单文件，含全部前端逻辑） |
| `fetch.py` | 云端抓取起始价，写出 `data.json` |
| `.github/workflows/fetch.yml` | 定时任务（见下表） |
| `data.json` | 数据文件（由任务自动生成、自动提交） |

## 更新节奏（北京时间）

| 时间 | 对应节点 |
|---|---|
| 10:17 / 10:22 | 商品 10:15 休盘档（10:30 开盘前参考；10:22 为保险轮） |
| 11:32 | 商品 11:30 午收档（13:30 开盘前参考） |
| 15:02 / 15:22 | 日盘 15:00 收盘档（15:22 为保险轮） |
| 23:02 | 夜盘 23:00 收盘档 |
| 01:02 / 02:32 | LME 有色 01:00 / 贵金属 02:30 收盘档 |
| 05:50 | 美股日线定格（05:30 之后） |

- 数据没有变化时不会产生提交（周末空跑无副作用）
- 想立刻刷新数据：Actions 页 → 左侧 `fetch` → **Run workflow**，约 2 分钟跑完，网页自动读到新数据

## 说明

- 行情来自新浪 / 腾讯等公开接口：免费源可能有延迟或偶发缺失（缺失显示「—」），以行情软件为准
- 美国期货免费数据行业惯例延时约 10 分钟；新浪经自建中转为准实时（滞后 8-20 秒）
- 不构成投资建议
